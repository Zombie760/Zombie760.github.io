BOTWAVE — Browser

Firefox. 49 C++ patches.
Detection is the problem.

BotFox is Firefox hardened with Camoufox — 49 C++ anti-detection patches applied at the browser core. It is the interactive browser BOTWAVE uses for manual bounty hunting and OSINT work where a vanilla browser fingerprint would trigger WAF challenges or behavioral detection before the first request lands. Native HAR capture is always on. Per-tab proxy rotation is built in. Open source. Free to install.

── Feature set

Built for the work, not the demo.

Every feature addresses a specific failure mode in vanilla Firefox that costs a bounty hunter either a finding or an IP. Nothing is added for its own sake.

Feature What it solves How it works
Camoufox core (49 patches) Browser fingerprint triggers WAF challenge before request lands C++ patches to canvas, WebGL, AudioContext, font enumeration, Navigator, screen resolution, and 40+ additional detection surfaces
Native HAR capture DevTools HAR export is manual — you miss the first requests on page load HAR recording begins at tab creation, not DevTools open. Every request logged to a timestamped file on disk automatically
Per-tab proxy rotation Single proxy per session means one burn kills the whole session Each browser context (tab group) routes through an independently assigned proxy. Context isolation means one flagged tab does not contaminate the others
Fingerprint-locked device profiles Fingerprint changes between sessions expose automation Device profiles lock canvas hash, User-Agent, screen resolution, and hardware concurrency to a consistent set. The same profile produces the same fingerprint on every session
TLS key logging Encrypted traffic not visible in Wireshark SSLKEYLOGFILE wired into the browser profile. Import the key log into Wireshark and decrypt TLS sessions from capture files after the fact
WAVESOX integration Manual proxy config required per session Points at the local WAVESOX pool API. Pulls a fresh validated proxy on each new context without manual configuration

── Installation

Three commands.

BotFox is open source. The install script handles the Camoufox build, profile setup, and optional WAVESOX proxy integration. Linux only — tested on Fedora and Ubuntu. Requires a GPU if you want the full headless anti-detection stack for automation work.

Install BotFox Shell 
# Clone and install
git clone https://github.com/Zombie760/botfox
cd botfox
./install.sh

# Launch with a named device profile
botfox --profile mac_m3pro

# Launch with WAVESOX proxy pool integration
botfox --profile mac_m3pro --proxy-pool http://localhost:8081

# Enable TLS key logging for a session
SSLKEYLOGFILE=~/keys/session_$(date +%s).log botfox --profile mac_m3pro
Profile config — what a device profile locks JSON 
{
  "name":              "mac_m3pro",
