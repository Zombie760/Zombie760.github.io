The Method — BOTWAVE PAPERWORK

Every claim filed. Every source named. A single unanchored claim is the lever a critic uses to dismiss the whole work. We do not write one.

Acceptable primary sources: a filed document with an archive reference. A court record with case number and court. A signed treaty, cable, or memorandum with date, signatory, and archive location. A contemporary newspaper of record with date and page. A peer-reviewed monograph citing the above. Trial testimony with volume and page.

If a claim cannot be anchored to one of those, it is cut. No "widely reported." No "it is believed." No anonymous sourcing. No inference presented as fact. The document is named or the sentence does not appear.

This is not a standard. It is a pipeline. Every manuscript in this catalog has been processed through TELOS + PAI — the Purpose + Automated Instruction substrate built on Daniel Miessler's open-source framework. Scout → Recorder → Writer → Editor → Verifier. The gate is hard-coded. It cannot be bypassed.

BOTWAVE PAPERWORK — For Independent Writers

What this imprint is for

BOTWAVE PAPERWORK exists for independent journalists, documentary filmmakers, and writers who are building document-grade work outside the traditional publishing apparatus. The substrate — the claim chain, the source taxonomy, the verification pipeline — is open architecture. We publish our own work first. We document the method as we go. The pipeline is reproducible.

If you are a writer working at this standard and want to know how the pipeline works, the source is public on GitHub.

What we publish

  • Investigation-grade non-fiction anchored to primary sources
  • Sports memoir grounded in documented record
  • Fiction built on the same source substrate as the non-fiction
  • Method documentation for journalists and researchers

We do not publish speculation, anonymous sourcing, or inference presented as fact. We do not accept work that cannot pass the Prime Directive gate.
