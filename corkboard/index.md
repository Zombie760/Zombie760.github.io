# Corkboard

Interactive entity maps for *Unwarranted Influence*. People, documents, institutions, events, and the connections between them — every node tied to a primary source.

## Boards

### [Main corkboard](main.html)

The primary entity graph. 93 people, 63 documents, 45 institutions, 49 events, 91 connections. Filed sources for every node.

### [Conspiracy filter](conspiracy.html)

The same data set, re-rendered to show what the standard "conspiracy" reading misses: the documents are real, the names are filed, the connections are signed.

### [Visual corkboard](banksy_corkboard.html)

A typographic / visual presentation of the same entities. Same primary sources, different render.

## Source

The book itself: [github.com/Zombie760/unwarranted-influence](https://github.com/Zombie760/unwarranted-influence). Every claim in the corkboard is backed by a citation in the book.
