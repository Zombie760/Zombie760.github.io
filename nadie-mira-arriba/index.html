BOTWAVE · Arcade independiente

Nadie Mira Arriba

Cuatro actos. Siete armas. Mira hacia El Cielo.

Acompaña a Cruz entre cartas vivas, rivales y luces de feria. Juega desde el navegador o lleva la versión de prueba a Android.

Jugar en navegadorDownload APK · Android

Navegador: WebGL 2 y teclado o mando. La versión actual no incluye controles táctiles. Gira el móvil a horizontal y conecta un mando compatible.

Arte original de lotee · Godot 4.7.2 · 480 × 270

Controles

Teclado: A/D o flechas para moverte; Espacio salta; W/↑ mira arriba; Z agacha; X dispara; C granada; F/V golpe; Q cambia arma; Esc pausa.

Mando estándar: A salta, B agacha, RT dispara, RB granada, LT mira arriba, X golpe, Y cambia arma, Start confirma / pausa.

Confirma JUGAR con Enter, Espacio, A o Start. El navegador puede pedir una interacción para activar el sonido.

Android · APK de prueba

Debug APK, no una versión de Play Store ni un lanzamiento de producción. Descarga de 58,0 MiB (60.851.616 bytes), para Android arm64 o x86_64.

  1. Descarga el APK desde este botón.
  2. Android puede pedir permiso para instalar aplicaciones desconocidas desde tu navegador o gestor de archivos.
  3. Abre el APK y confirma la instalación. Desactiva ese permiso después si lo deseas.

Paquete: com.lotee.nadiemiraarriba. Los APK solo se instalan en Android; no en iPhone/iPad. No requiere una cuenta de GitHub para descargar.
